# Project Roadmap

## Purpose

This roadmap defines the planned development stages of the Roman Dodecahedron Open Research Project (RDORP). It serves as the primary planning document and tracks the evolution of the repository.

Unlike the Project Charter, this document is expected to evolve throughout the lifetime of the project.

---

# Current Status

**Current Project Version:** 0.1.0

**Current Phase:** Foundation

---

# Milestone M1 — Foundation

## Objective

Establish the governance, documentation, and repository structure.

### Deliverables

* README.md
* PROJECT_CHARTER.md
* ROADMAP.md
* RESEARCH_METHOD.md
* DATABASE_SCHEMA.md
* DATA_DICTIONARY.md
* DATA_COLLECTION_PROTOCOL.md
* SOURCE_EVALUATION.md
* CONTRIBUTING.md
* CHANGELOG.md

### Success Criteria

* Repository structure finalized.
* Documentation internally consistent.
* Research methodology approved.
* Database schema frozen for Version 1.

---

# Milestone M2 — Database Infrastructure

## Objective

Create the project's master database and validation framework.

### Deliverables

* Master CSV dataset
* SQLite database
* SQL schema
* Import/export scripts
* Data validation scripts
* Unique identifier system

### Success Criteria

* Database schema implemented.
* Import workflow operational.
* Data validation automated.

---

# Milestone M3 — Specimen Catalogue

## Objective

Document every publicly known Roman dodecahedron.

### Deliverables

Each specimen should include, where available:

* Identifier
* Findspot
* Museum
* Inventory number
* Discovery context
* Measurements
* Hole diameters
* Decorative features
* References
* Source confidence
* Notes

### Success Criteria

* All known specimens entered.
* Every record contains at least one primary or authoritative secondary reference.
* Data validation completed.

---

# Milestone M4 — Literature Database

## Objective

Create a comprehensive bibliography of Roman dodecahedron research.

### Deliverables

* Books
* Journal articles
* Conference papers
* Museum publications
* Excavation reports
* Online resources

### Success Criteria

* Bibliographic database searchable.
* References linked to specimen records where applicable.

---

# Milestone M5 — Geometry & 3D Reconstruction

## Objective

Develop accurate digital representations of documented specimens.

### Deliverables

* Parametric geometry specification
* Blender models
* STL
* OBJ
* GLB
* Measurement documentation

### Success Criteria

* Reconstructed models traceable to published measurements.
* Reconstruction assumptions documented.

---

# Milestone M6 — Engineering Analysis

## Objective

Evaluate the engineering characteristics of Roman dodecahedra.

### Deliverables

* Structural analyses
* Mechanical assessments
* Manufacturing studies
* Functional compatibility studies
* Wear expectation models

### Success Criteria

* Engineering workflow documented.
* Analyses reproducible.

---

# Milestone M7 — Experimental Archaeology

## Objective

Test selected hypotheses through controlled experiments.

### Deliverables

Possible experiment categories include:

* Structural node concepts
* Wooden rod assemblies
* Rope routing and fastening
* Load testing
* Repeated assembly
* Wear generation
* Field reconstruction

### Success Criteria

* Experiments documented.
* Protocols reproducible.
* Results linked to hypotheses.

---

# Milestone M8 — Computational Analysis

## Objective

Apply computational methods to the complete dataset.

### Deliverables

* Statistical analysis
* GIS analysis
* Graph analysis
* Pattern recognition
* Clustering
* Comparative datasets

### Success Criteria

* All scripts reproducible.
* Results generated directly from repository data.

---

# Milestone M9 — Publication

## Objective

Publish the first stable research release.

### Deliverables

* Version 1.0 dataset
* Documentation
* Analytical reports
* 3D model archive
* Public release package

### Success Criteria

* Complete repository documentation.
* Verified dataset.
* Reproducible workflows.
* Publicly citable release.

---

# Long-Term Goals

The project aims to become:

* a reference dataset for Roman dodecahedron research,
* an open collaboration platform,
* a reproducible scientific resource,
* a foundation for future archaeological, engineering, and computational studies.
