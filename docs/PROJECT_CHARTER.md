# Project Charter

## 1. Purpose

The **Roman Dodecahedron Open Research Project (RDORP)** is an evidence-based research initiative dedicated to documenting, preserving, and analyzing all known Roman dodecahedra.

The project aims to provide a transparent, reproducible, and extensible research platform that supports archaeological, historical, engineering, geometrical, statistical, and computational investigations.

RDORP does not advocate a preferred interpretation of Roman dodecahedra. Instead, it provides a common evidence base against which competing hypotheses can be objectively evaluated.

---

# 2. Mission

To build the world's most comprehensive open research dataset on Roman dodecahedra.

The project integrates:

* Archaeological evidence
* Museum documentation
* Published literature
* Geometrical measurements
* Digital 3D reconstructions
* Experimental archaeology
* Engineering analysis
* Computational methods

into a single, version-controlled repository.

---

# 3. Vision

RDORP seeks to become the primary open reference resource for Roman dodecahedron research.

The long-term objective is not to establish a definitive explanation for these artifacts but to provide the highest-quality evidence from which future research can draw reproducible conclusions.

---

# 4. Scope

The project includes:

* Known Roman dodecahedron specimens
* Archaeological metadata
* Museum information
* Bibliographic references
* Measurements
* Hole geometry
* Decorative features
* Geographic information
* Digital reconstructions
* Experimental results
* Statistical analyses
* Engineering evaluations

The project may also include newly discovered specimens as they become publicly documented.

---

# 5. Out of Scope

The project does not:

* Present speculation as fact.
* Modify archaeological measurements without documenting the source.
* Replace museum documentation.
* Publish copyrighted material without permission.
* Promote unsupported theories.

---

# 6. Core Principles

## Evidence First

Observations always take precedence over interpretation.

## Source Traceability

Every recorded value must reference its original source whenever possible.

## Reproducibility

All analyses should be reproducible from the published dataset and documented methods.

## Transparency

All assumptions, estimates, and derived values must be explicitly identified.

## Neutrality

The repository does not favor any hypothesis before evaluation.

---

# 7. Data Principles

The repository distinguishes between:

* Observed data
* Derived data
* Interpretations

These categories must never be mixed.

Unknown values remain empty rather than estimated.

---

# 8. Repository Structure

The repository is organized into four logical layers:

1. Documentation
2. Evidence
3. Analysis
4. Research

Each layer depends on the previous one but never modifies it.

---

# 9. Research Workflow

The standard workflow is:

1. Collect evidence.
2. Verify sources.
3. Record structured data.
4. Validate data quality.
5. Perform analysis.
6. Conduct experiments where appropriate.
7. Evaluate hypotheses.
8. Publish results.

Hypothesis evaluation is the final stage of the workflow.

---

# 10. Deliverables

The project aims to produce:

* Structured specimen database
* Bibliographic database
* Museum catalogue
* GIS dataset
* Parametric 3D models
* Experimental archaeology reports
* Engineering analyses
* Statistical analyses
* Open documentation

---

# 11. Governance

The repository follows these rules:

1. One specimen equals one primary record.
2. Every fact has at least one cited source.
3. Unknown information remains unknown.
4. Corrections are versioned rather than overwritten.
5. Interpretations never replace observations.

---

# 12. Success Criteria

The project will be considered successful when it provides:

* A comprehensive catalogue of known Roman dodecahedra.
* A fully documented and referenced research database.
* Reproducible analytical workflows.
* Open documentation suitable for academic collaboration.
* A sustainable foundation for future archaeological and engineering research.
