# RDORP Decision Model

## Purpose

Define a reproducible decision framework for evaluating competing functional hypotheses for Roman dodecahedra.

## Primary Research Question

Which functional hypothesis is best supported by the complete body of archaeological, geometrical, engineering, and experimental evidence?

## Decision Pipeline

Research Question
→ Functional Hypotheses
→ Observable Predictions
→ Evidence Variables
→ Artifact Measurements
→ Comparative Evaluation
→ Ranked Hypotheses

## Functional Hypotheses

- H001 Structural connector / modular node
- H002 Measuring instrument / rangefinder
- H003 Ritual object
- H004 Candlestick or lamp support
- H005 Textile / knitting tool
- H006 Astronomical instrument
- H007 Military equipment
- H008 Portable shrine component

## Evidence Categories

1. Geometry
2. Manufacturing
3. Wear
4. Archaeological Context
5. Experimental Archaeology

## Decision Principles

- Observations are recorded before interpretation.
- Each evidence variable must discriminate between at least one pair of hypotheses.
- Unknown evidence remains unknown.
- New artifact data update hypothesis evaluations without changing historical observations.

## Scoring Concept (v0.1)

For each hypothesis and evidence variable:

+2 Strongly supports
+1 Supports
 0 Neutral / non-discriminatory
-1 Weakly contradicts
-2 Strongly contradicts

Confidence is tracked separately from score.

## Outputs

- Ranked hypotheses
- Evidence gaps
- Sensitivity analysis
- Recommendations for future measurements and experiments
