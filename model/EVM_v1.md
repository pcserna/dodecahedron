# RDORP Evidence Variable Model (EVM) v1.0

## Purpose

This document defines the minimum set of evidence variables required to discriminate
between competing functional hypotheses for Roman dodecahedra.

Only variables with potential discriminatory value are included.

## Categories

### Geometry
EV001 Overall dimensions
EV002 Mass
EV003 Wall thickness
EV004 Hole diameter distribution
EV005 Opposite-hole relationships
EV006 Hole taper/profile
EV007 Knob diameter
EV008 Knob symmetry
EV009 Face symmetry
EV010 Manufacturing tolerances

### Manufacturing
EV011 Alloy composition
EV012 Casting quality
EV013 Casting defects
EV014 Surface finishing
EV015 Repair evidence
EV016 Secondary machining

### Wear
EV017 Internal hole wear
EV018 External edge wear
EV019 Rope wear
EV020 Rotational wear
EV021 Impact damage
EV022 Abrasion
EV023 Thermal alteration
EV024 Residues

### Archaeological Context
EV025 Site type
EV026 Roman province
EV027 Associated finds
EV028 Stratigraphic context
EV029 Dating
EV030 Number of associated dodecahedra
EV031 Military association
EV032 Ritual association

### Engineering
EV033 Rod compatibility
EV034 Rope compatibility
EV035 Structural stability
EV036 Load path feasibility
EV037 Modular assembly potential
EV038 Orientation dependence

### Comparative
EV039 Standardisation across specimens
EV040 Regional variation

Each variable should be measured or recorded objectively.
Interpretations belong in the hypothesis evaluation stage.
