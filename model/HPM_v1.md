# HPM v1.0 — Hypothesis Prediction Matrix

## Purpose

The HPM defines the **expected observations** for each evidence variable if a
functional hypothesis is correct.

It does **not** contain observations from artifacts.

## Rating Scale

- ++ Strongly expected
- + Expected
- 0 Neutral / not diagnostic
- - Unlikely
- -- Strongly contradictory

## Hypotheses

H001 Structural Connector / Modular Node
H002 Measuring Instrument / Rangefinder
H003 Ritual Object
H004 Candlestick / Lamp Support
H005 Textile Tool
H006 Astronomical Instrument
H007 Military Equipment
H008 Portable Shrine Component

## Interpretation

The matrix represents prior engineering and archaeological expectations.
Artifact observations will later be compared against these expectations.
